# Four-Domain IQ Test

A 40-item timed IQ test that runs entirely in the browser: matrix reasoning, number series, verbal & logic, and backward digit span.

Responses are scored with a three-parameter item-response model (EAP estimate on a normal prior) and reported on the standard IQ scale (mean 100, SD 15) with a 90% confidence range and per-section indices.

Item difficulties are calibrated from published research on these item types, not from a norming sample, so results are an estimate, not a clinical assessment.

Static site: just `index.html`. No build step.
